# Платформа обучения ЦРП

Платформа для **Центра Развития Предпринимателей** (crp.kz):

- **обучение сотрудников ЦРП** — курсы, назначения со сроками, тесты, отчёты руководителю;
- **платные курсы для клиентов ЦРП** — курс публикуется, клиент оплачивает, после подтверждения оплаты получает доступ;
- позже — **места для сотрудников компаний-клиентов** (B2B).

Разработка — SalemAI. Статус: **MVP собран** — витрина, курсы с тестами,
сертификаты с QR, покупка с подтверждением админом, назначения и отчёт
руководителя, конструктор курсов, ru/kz. Стиль — как редизайн сайта ЦРП.
Новое — за флагами (в демо включены, на проде — после приёмки, D-025). Уже есть:
очередь писем и раздел «Письма» в админке, восстановление пароля, подтверждение email
(письмо при регистрации и по кнопке в плашке), напоминания о сроках и сводка руководителю,
PDF сертификата, страницы юридических документов (тексты — черновики-заглушки, настоящие
готовит юрист ЦРП), согласия с хэшем текста при регистрации и покупке, загрузка файлов и
картинок в конструкторе. Ждут решения владельца и пока работают за флагами: заказ только с
подтверждённого email (D-032, входит во флаг EMAIL_VERIFY) и две галочки на покупке (D-035,
входят во флаг LEGAL) — эти флаги на проде не включать до решения. Письма на проде начнут
уходить после выбора почтового провайдера ЦРП (D-030) и подключения крона из комплекта
выкладки; до этого почтовые функции видны только в демо, раздел «Письма». В работе: комплект
выкладки на сервер ЦРП.

## Посмотреть

Скриншоты основных экранов — [`docs/screens/mvp-overview.png`](docs/screens/mvp-overview.png).

**Локально** (Node 22):

```bash
npm install
npm run dev        # http://localhost:3000 — демо без базы, данные из сида
```

**Превью в Vercel** (один раз):
1. Vercel → Add New → Project → импортировать `salemaikz/crp-kz`.
2. Нажать Deploy — переменные не нужны: без `DATABASE_URL` на Vercel
   включается демо (D-019).

**Превью в Netlify:** демо можно выложить и туда. В репозитории есть `netlify.toml`;
в переменных сайта задать `DEMO_MODE=1` и `NODE_VERSION=22` (D-024).

Пока нет ветки `main`, рабочая ветка — `claude/amazing-pascal-agse3o`.

**Демо-доступ** — кнопки на странице входа (пароль для всех `demo12345`):

| Кто | Что посмотреть |
|---|---|
| Предприниматель (`client@crp.demo`) | «Моё обучение», урок с тестом, сертификат |
| Сотрудник ЦРП (`operator@crp.demo`) | назначенный курс со сроком, уроки по порядку |
| Руководитель (`manager@crp.demo`) | «Команда»: назначить курс, отчёт, выгрузка CSV |
| Администратор (`admin@crp.demo`) | конструктор курсов, заказы («Оплачено»), пользователи |

Покупка: войти → курс → «Купить» → заказ → под администратором «Оплачено» →
доступ открыт. Тексты курсов — демо, цены — заглушки до материалов ЦРП.

В демо письма не отправляются: их видно в админке, раздел «Письма», вместе со ссылкой из
письма. Например: вход → «Забыли пароль?» → адрес своей новой учётки → «Письма» под
администратором → ссылка. Для демо-учёток из таблицы сброс намеренно не выполняется.

Данные демо живут в памяти серверной функции. Новое — заказы, письма, загруженные файлы —
видно, пока запросы попадают на тот же экземпляр функции; после простоя или на другом
экземпляре демо возвращается к исходным данным. Загруженные документы в демо видит только
администратор (D-038).

## Прод

Комплект выкладки на сервер ЦРП в РК — в работе (волна 5): runbook `docs/ops/RUNBOOK.md`
(выкладка и бэкапы), первый администратор — `npm run admin:create`, проверка окружения —
`npm run ops:preflight`. Пока этих файлов и команд нет.
