# Motion-ролики ЦРП

Короткие анимированные ролики в стиле ЦРП для соцсетей и презентаций. Задача — #28.
Каждый ролик — папка со сценой `index.html`; общие рендер (`render.mjs`) и синтез звука (`sound.mjs`).

## «Из чего складывается выручка» — `revenue/`

| Что | Значение |
|---|---|
| Файл | `revenue/crp-revenue-1920x1080.mp4` |
| Формат | 1920×1080, 60 fps, H.264, BT.709; звук AAC 48 кГц стерео, пик −3 дБ (в этой сборке около −19 LUFS) |
| Длительность | 47,5 с |

| Время, с | Что на экране |
|---|---|
| 0–3,9 | Крупное «Выручка» и строка «Из чего она складывается»; слово уменьшается и встаёт в формулу «Выручка =» |
| 3,8–4,6 | Четыре пустые ячейки формулы |
| 4,6–19 | Камера приближается и по очереди показывает крупно: заявки, конверсия, средний чек, частота покупок; затем отъезжает |
| 19,8–23 | Пример: 1 000 × 10% × 50 000 ₸ × 1,2 раза = 6 000 000 ₸ |
| 23–28 | Каждый множитель +10%: 1 100 × 11% × 55 000 ₸ × 1,32 раза = 8 784 600 ₸, +46% |
| 28–31 | +46% на весь экран: «Если каждый множитель вырастет на 10%» |
| 31–41,5 | +46% улетает в конец полосы; полоса растёт четырьмя отрезками по 10% от уже выросшей суммы |
| 41,5–47,5 | Тёмная панель: белый логотип, «Записаться на бесплатный разбор», crp.kz |

Цифры — условный пример. Подпись «Пример расчёта» держится на экране с первой цифры до финала.
Это не данные ЦРП и не обещание результата: +46% — арифметика, 1,1⁴ = 1,4641.

## Стиль

По `docs/brand/BRAND.md`: доска `--board`, графит `--ink`, Geologica 700 и Onest. Красный —
маркер: прогресс множителей (красная полоса на `--line`, как компонент прогресса платформы),
ключевая цифра +46% (`--red-ink`), отрезки роста и кнопка в финале. Логотип —
`crp-logo-white.svg` из `docs/brand/logo/` на `--deep`, без изменений.

Без колец, свечения, размытия, теней, стрелок, иконок, надписей над заголовком и
сгенерированных картинок (раздел «Без ИИ-шума», D-023). Движение — камера по формуле, сдвиг из-под
маски, смена значения в слоте, рост полос и сквозные переходы (слово и цифра переезжают из сцены в
сцену). Три кривые на всё: появление, уход, перемещение.

## Звук

`sound.mjs` синтезирует дорожку по списку `CUES` из сцены. Сэмплов, библиотек и ИИ нет:
- тик — появление текста и смена значений;
- нота «маримбы» — заставка, каждый множитель, сумма примера, полоса «Было»; мотив до–ре–ми–соль
  повторяется, когда растут отрезки полосы;
- «вжух» — пролёт камеры и смена сцены;
- колокольчик — +46% и логотип в финале;
- мягкий низкий удар — +46% на весь экран и финальная панель.

Шум генерируется с фиксированным зерном, поэтому дорожка от сборки к сборке одинаковая.

## Как пересобрать

Нужны `npm ci`, Chromium для Playwright и `ffmpeg` с `libx264` в `PATH`. Из корня репозитория:

```sh
node docs/brand/motion/render.mjs revenue                        # MP4 со звуком в папку сцены
node docs/brand/motion/render.mjs revenue --fps 30 --out /tmp/crp.mp4
node docs/brand/motion/render.mjs revenue --frames 2000,22000    # PNG стоп-кадров во временную папку
node docs/brand/motion/render.mjs revenue --serve                # превью в браузере, без звука
```

Превью: сервер слушает только 127.0.0.1 и отдаёт только `docs/brand/` и `assets/fonts/`;
по `file://` шрифты не загрузятся. Параметр `?t=22000` — стоп-кадр на 22-й секунде.

Рендер пишет во временный `.part` и заменяет MP4 только после успешной сборки, поэтому
прерванный запуск не портит готовый ролик.

Тайминг — объект `T` в `index.html` сцены. Анимация построена на Web Animations API на паузе:
рендер выставляет время каждому кадру через `seek()`, поэтому превью и видео совпадают кадр в
кадр. Новая сцена — папка с `index.html`, который отдаёт `window.ready`, `window.DURATION`,
`window.seek(ms)` и, если нужен звук, `window.CUES`.
