# Motion-ролики ЦРП на Remotion

Отдельный проект на [Remotion](https://www.remotion.dev) (React → кадры → MP4). Ролики на
HTML-сценах — в соседних папках, см. `../README.md`. Задача — #28.

> **Лицензия Remotion — решение D-039 (предложено).** Бесплатно — частным лицам, некоммерческим
> организациям, компаниям до 3 сотрудников и на время оценки. Компании больше нужна платная Company License:
> https://www.remotion.pro/license. До решения владельца проект пробный: ролики из него **не
> публиковать** и не хранить в git (`*.mp4` в `.gitignore`), их собирают локально.

## Композиции

### `Funnel2` — «Где теряются заявки», версия 2 (37 с)

Ритм — 120 BPM, движение попадает в доли.
- **Хук на тёмном.** Одна красная точка и три фразы: «1 000 заявок.», «60 покупок.», «Остальные 940
  теряются по пути». На сильную долю точка взрывается тысячей заявок, сквозь неё раскрывается доска.
- **Камера едет за заявками.** Каждый этап — свой экран: крупная цифра и подпись слева, куча точек
  справа. Потерянные краснеют и падают вниз, в куче остаётся серый след; дошедшие перелетают, камера
  панорамирует вместе с ними.
- **Общий план.** Камера отъезжает — видны все четыре этапа. Дозвон 75%: 150 серых снова в игре,
  каскад 750 → 300 → 75; на каждом этапе дальше идёт та же доля из новых, остальные теряются.
- **Наезд на итог** «75» и финал: логотип, «Записаться на бесплатный разбор» (кнопка с главной
  crp.kz, `docs/brand/reference/site-hero.webp`), crp.kz.

### `Funnel` — версия 1 (40,4 с)

Те же цифры одним планом: четыре кучи как столбики диаграммы, потерянные сереют, оставшиеся
перелетают; приближение к первым этапам и тот же каскад.

### Общее

Цифры — условный пример, подпись «Пример расчёта» на экране с первой цифры:
1 000 × 60% × 40% × 25% = 60; 1 000 × 75% × 40% × 25% = 75.

Стиль — `docs/brand/BRAND.md`, раздел «Без ИИ-шума» (D-023): доска и графит, тёмные `--deep`
только в хуке и финале, красный — маркер (потери в момент потери, итоговые покупки, кнопка).
Звук и бит синтезирует `../sound.mjs` по сигналам сценария — без сэмплов и ИИ.

## Устройство

| Файл | Что |
|---|---|
| `src/funnel2/timeline.ts`, `src/timeline.ts` | данные, тайминг, камера, тексты и звуковые сигналы — общий источник для картинки и звука |
| `src/funnel2/world.ts`, `src/dots.ts` | модель точек: где стоят, когда летят или падают, как меняют цвет; счётчики |
| `src/funnel2/Funnel2.tsx`, `src/Funnel.tsx` | композиции |
| `src/parts.tsx` | общие части: счётчик, смена текста, финальная карточка |
| `src/brand.ts` | токены (копия `docs/brand/tokens.css`), шрифты, кривые |
| `scripts/prepare.mjs` | кладёт в `public/` шрифты из `assets/fonts/pdf`, логотип из `docs/brand/logo` и синтезирует `sfx-<композиция>.wav` |

`public/` собирается скриптом и не хранится в git: единственный источник шрифтов и логотипа —
бренд-папки репозитория.

## Как запустить

Нужен Node.js 22.18+ или 24+ (скрипт подготовки импортирует `.ts` напрямую). Из этой папки:

```sh
npm ci
npm run dev                                   # Remotion Studio: превью и таймлайн
npm run render                                # Funnel → crp-funnel-1920x1080.mp4
npx remotion render Funnel2 crp-funnel-v2-1920x1080.mp4   # после npm run prepare-assets
npm run still -- out/f.png --frame=600        # один кадр Funnel
npm run lint                                  # eslint + tsc
```

Remotion сам скачивает Chrome Headless Shell. Если сеть его не пускает, укажите локальный
Chromium: `--browser-executable=/путь/к/headless_shell`.
