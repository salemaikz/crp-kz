# Дорожная карта LMS

Каждый пункт — issue в GitHub с меткой уровня (`tier:T0/T1/T2→T1/T2`, см.
`docs/agents/ROUTING.md`) и этапа. **MVP** = пункты с отметкой ✅ (граница MVP —
`docs/lms/SPEC.md` §9). Порядок внутри этапа учитывает зависимости. Сроки
привязываются после решения владельца о приоритете и ресурсах. Вопросы
владельцу собраны в [#1](https://github.com/salemaikz/crp-kz/issues/1).
